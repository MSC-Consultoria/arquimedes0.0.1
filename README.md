## Regras de curadoria

- não fazer merge integral das branches antigas;
- comparar e aproveitar arquivos individualmente;
- eliminar segredos e dependências obsoletas;
- validar licença, dados pessoais e direitos sobre os conteúdos;
- registrar na Alexandria o que foi aproveitado;
- remover branches depois da decisão;
- arquivar o repositório após concluir a curadoria mínima.

Não existe atualmente um repositório sucessor separado para consultoria ou laboratório de IA. Novos repositórios só serão criados quando houver produto ativo e fronteira operacional clara.
